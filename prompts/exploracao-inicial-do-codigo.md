# Exploração incial para criação do CLAUDE.md

Vamos usar essa sessão para fazer um estudo inicial do código fonte do projeto e escrever na memória do claude `CLAUDE.md`.

Utilize o commando built in do claude /init para iniciar a pesquisa sobre o projeto com base no código fonte.

O objetivo é mapear e identificar qual a arquitetura existente no código:

1. Qual a linguagem de programação utilizada
2. Quais as principais dependências
3. Qual é o banco de dados utilizado na aplicação
4. Caso exista alguma dependência ORM, informar qual ORM.
5. Qual a ferramenta de versionamento de banco de dados (Migrações) caso exista.
6. Qual o tipo da applicação? Web app? API HTTP? Aplicação CLI?
7. Existe alguma informação sobre a infrastrutura da applicação? Qual o provedor? Utiliza-se IaC?
8. Existe alguma pipeline de CI/CD? Quais?

Adicione informações úteis sobre qual é o problema que o projeto propõem a solucionar.

Assim que você concluir um mapeamento completo sobre o projeto, escreva o arquivo CLAUDE.md para manter essas informações relevantes sobre o projeto, na memória de cada sessão.

**Importante**: Desconsidere os arquivos `README.md` e `TRANSCRICAO.md` ao realizar suas pesquisas. Esses arquivos foram adicionados para instruir sobre o desafio e portanto não quero mencionar eles na memória.
